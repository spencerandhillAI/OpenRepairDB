# OpenRepairDB — project vision

OpenRepairDB is a noncommercial, donation-supported, open-source repair knowledge database.

## Goals
- Searchable, attributable information about devices, circuit boards, components and repair cases/instructions.
- Traceable links between devices, boards, components and repairs, only where evidenced.
- Useful device detail pages: what it is, capabilities, technical specifications, pin labels/pinouts where documented, and further reading.
- Community contributions, moderation, roles and media as future features.
- Reliable search: homepage category tiles show newest records; regular text search should rank by relevance.
- Transparent distinction between verified guides and unverified repair attempts.

## Data policy
Technical details live in PostgreSQL or maintained data files, not application source. Do not invent missing information. Preserve sources and licensing information. Third-party source rights must be checked individually.
