# Contributing to OpenRepairDB

Thank you for helping build an open repair knowledge base.

The project is in its foundation phase. Until the contribution workflow is implemented, use GitHub Issues and Pull Requests for project and documentation changes.

## Technical contributions

- Keep changes focused and explain the reason for them.
- Never commit passwords, API keys, tokens, personal data or private service documents.
- Do not add third-party images, manuals, schematics or copied text unless redistribution is permitted.
- Include source links and licence details for externally derived material.
- Do not present guesses, AI-generated content or unverified compatibility as established facts.

## Repair knowledge

A useful repair report should include, where known:
- exact manufacturer and model identifiers,
- board/module identifier and revision,
- symptoms and fault codes,
- diagnostic steps and measurement conditions,
- repair performed and parts used,
- outcome and whether the repair was verified,
- safety warnings,
- source and evidence.

## Safety

Do not publish instructions that encourage bypassing protective devices or defeating safety interlocks. Mains-voltage, high-energy battery and other hazardous procedures require prominent warnings and appropriate qualifications.

## Content rights

Contributors must have the rights needed to submit any text, image or file and must provide applicable attribution and licence information. Submitting material does not grant permission to copy unrelated third-party content.

## Questions

Open a GitHub Issue for questions, proposals or suspected errors.
